================================================================================
GUIDE DE USO - SISTEMA DE CONSULTA DE DÉBITOS
================================================================================

1. INSTALAÇÃO
================================================================================

1.1. Instalar dependências Python:
    pip3 install -r requirements.txt
    
1.2. Instalar Playwright:
    playwright install
    
1.3. Instalar navegador (Chrome/Chromium):
    playwright install chromium
    
2. ESTRUTURA DO SISTEMA
================================================================================

main.py                          - Interface gráfica principal (GUI)
analyze.py                      - Script para analisar a página web
config.py                       - Configurações do sistema
models.py                       - Modelos de dados
database.py                     - Gerenciamento de planilhas
scraper/scraper.py             - Lógica de scraping com Playwright
test_sample.py                 - Exemplos e testes
install.sh                     - Script de instalação
errors.log                     - Log de erros (gerado automaticamente)

3. COMO USAR
================================================================================

3.1. Carregar Planilha de Entrada:
    - Inicie o sistema: python main.py
    - Clique em "Escolher planilha..."
    - Selecione arquivo CSV ou XLSX com lista de CPFs e nomes
    - O sistema mostrará uma prévia dos dados

3.2. Executar Consulta:
    - Clique em "Executar Consulta"
    - O sistema processará os débitos em paralelo
    - Barra de progresso mostrará o status em tempo real

3.3. Verificar Resultados:
    - Após conclusão, planilha de saída será gerada automaticamente
    - Erros serão registrados em errors.log

4. FORMATO DA PLANilha DE ENTRADA
================================================================================

A planilha de entrada deve conter as seguintes colunas:

| Coluna | Descrição | Exemplo |
|--------|-----------|---------|
| Nome | Nome completo do devedor | João Silva |
| CPF | CPF do devedor | 123.456.789-00 |
| Tipo Débito | Tipo de débito (opcional) | ICMS |
| Competência | Ano/competência (opcional) | 2024 |
| Valor (R$) | Valor do débito (opcional) | 150.00 |

Exemplo de arquivo CSV:
```
Nome,CPF,Tipo Débito,Competência,Valor (R$)
João Silva,123.456.789-00,ICMS,2024,150.00
Maria Santos,987.654.321-00,ISS,2024,200.00
José Pereira,456.789.123-00,ICMS,2024,100.00
```

5. FORMATO DA PLANILLA DE SAÍDA
================================================================================

A planilha de saída conterá as seguintes colunas:

| Coluna | Descrição | Exemplo |
|--------|-----------|---------|
| Nome | Nome completo do devedor | João Silva |
| CPF | CPF do devedor | 123.456.789-00 |
| Tipo de Débito | Tipo de débito encontrado | ICMS |
| Competência | Ano/competência | 2024 |
| Valor (R$) | Valor do débito | 150.00 |
| Status | Status da consulta | COMPLETO/ERRO |

6. ANÁLISE DA PÁGINA WEB
================================================================================

Para analisar a estrutura da página e identificar elementos do DOM:

    python analyze.py

Este script mostrará:
- Elementos do formulário
- Campos de input (CPF, Nome)
- Botões (Pesquisar)
- Tabelas de resultados
- Cabeçalhos das tabelas
- Classes e IDs dos elementos

7. CONFIGURAÇÕES
================================================================================

7.1. Configurar no arquivo config.py:

    # URL base do sistema
    BASE_URL = "https://santanadoaraguaia-pa.desenvolvecidade.com.br/nfsd/pages/relatorio/relatorioLancamentoDebito.jsf"

    # Configurações de scraping
    MAX_CONCURRENT_REQUESTS = 50
    TIMEOUT_PER_REQUEST = 30
    RETRY_ATTEMPTS = 3

    # Configurações de lote
    LOTES_POR_CONSULTA = 50

    # Timeout do navegador
    BROWSER_TIMEOUT = 30

7.2. Elementos do DOM

Após análise da página, os elementos do DOM podem ser configurados:

    # Elementos do formulário
    CPF_INPUT_ID = "cpf_input_id"
    NOME_INPUT_ID = "nome_input_id"
    BUSCAR_BUTTON_ID = "botao_pesquisar_id"

8.2. Teste com arquivo de exemplo:

    # O sistema tentará consultar os dados do arquivo exemplo_input.csv

9. SOLUCIONAR PROBLEMAS
================================================================================

9.1. Erro de instalação:

    Se houver erro ao instalar dependências:
    - Verifique se Python está instalado: python --version
    - Atualize as dependências: pip3 install --upgrade pip
    - Execute como root: sudo pip3 install -r requirements.txt

9.2. Erro ao executar Playwright:

    Se houver erro ao inicializar Playwright:
    - Execute: playwright install
    - Verifique se os browsers estão instalados: playwright info

9.3. Erro de conexão:

    Se houver erro de conexão com a página:
    - Verifique se a URL está correta
    - Verifique se o navegador pode acessar a página
    - Verifique se há bloqueios de firewall

9.4. Erro de análise de página:

    Se analyze.py não funcionar:
    - Verifique se a página está acessível
    - Verifique se não há bloqueios de CORS
    - Tente abrir a URL manualmente no navegador

10. PERFORMANCE
================================================================================

10.1. Otimizações:

    O sistema utiliza:
    - Consulta paralela de múltiplos CPFs (até 50 simultâneas)
    - Timeout inteligente para evitar bloqueios
    - Retry automático (3 tentativas por consulta)
    - Processamento em lotes (50 CPFs por lote)

10.2. Ajustes de performance:

    - Aumente LOTES_POR_CONSULTA para mais paralelismo
    - Aumente TIMEOUT_PER_REQUEST para páginas mais lentas
    - Reduza RETRY_ATTEMPTS para evitar retry excessivo
