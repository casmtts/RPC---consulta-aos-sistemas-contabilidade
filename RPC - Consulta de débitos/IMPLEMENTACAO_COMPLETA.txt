================================================================================
🚀 PASSOS PARA INSTALAR E USAR:
================================================================================

PASSO 1: INSTALAR DEPENDÊNCIAS
-------------------------------
Na terminal, execute:

    pip3 install -r requirements.txt

PASSO 2: INSTALAR PLAYWRIGHT
-----------------------------
Na terminal, execute:

    playwright install

PASSO 3: INSTALAR BROWSER
-------------------------
Na terminal, execute:

    playwright install chromium

PASSO 4: ANALISAR PÁGINA (OPCIONAL)
------------------------------------
Para analisar a estrutura da página:

    python analyze.py

PASSO 5: TESTAR O SISTEMA
-------------------------
Para testar com dados de exemplo:

    python test_sample.py

PASSO 6: RODAR O SISTEMA
------------------------
Para iniciar a interface gráfica:

    python main.py

================================================================================
📊 FORMATOS DE ARQUIVO:
================================================================================

📥 PLANILHA DE ENTRADA (CSV/XLSX):
----------------------------------
Colunas:
- Nome (nome completo do devedor)
- CPF (CPF do devedor)
- Tipo Débito (opcional)
- Competência (opcional)
- Valor (R$) (opcional)

Exemplo:
```
Nome,CPF,Tipo Débito,Competência,Valor (R$)
João Silva,123.456.789-00,ICMS,2024,150.00
Maria Santos,987.654.321-00,ISS,2024,200.00
```

📤 PLANILHA DE SAÍDA (XLSX/CSV):
---------------------------------
Colunas:
- Nome
- CPF
- Tipo de Débito
- Competência
- Valor (R$)
- Status (COMPLETO/ERRO)

================================================================================
🔧 CONFIGURAÇÕES:
================================================================================

Editar config.py para ajustar:

- BASE_URL: URL do sistema de consultas
- LOTES_POR_CONSULTA: Quantidade de CPFs por lote
- TIMEOUT_PER_REQUEST: Tempo máximo por consulta
- RETRY_ATTEMPTS: Número de tentativas de retry
