## 1. BUG CRÍTICO: Importação de módulo `scraper` incorreta

### Arquivos afetados:
- `analisar_cookie.py` (linha 8)
- `analyze.py` (linha 12)
- `test_sample.py` (linha 9)

### Problema:
```python
from scraper.scraper import DebitorScraper
```

### Análise:
O caminho correto para o módulo é:
```
/Users/casmtts/Documents/TRIBUTOS E TERRA/RPC - Consulta de débitos/scraper/scraper.py
```

As importações devem ser:
```python
from scraper.scraper import DebitorScraper  # ❌ INCORRETO
# OU
from scraper.scraper import DebitorScraper  # ✅ CORRETO (se scraper.py estiver no path)
```

### Solução:
O módulo `scraper` é uma subpasta (`scraper/scraper.py`). A importação `from scraper.scraper import DebitorScraper` só funcionará se:
1. O módulo `scraper.py` estiver no diretório raiz (não é o caso)
2. O diretório `scraper` esteja no `PYTHONPATH`

**Recomendação:** Alterar para:
```python
from scraper.scraper import DebitorScraper
```
E garantir que:
```python
import sys
sys.path.insert(0, str(Path(__file__).resolve().parent))
```
Este código já está presente em `main.py` (linha 41), mas **NÃO** está em:
- `analisar_cookie.py`
- `analyze.py`
- `test_sample.py`

**Severidade: ALTA** - As importações falharão sem esta correção.

## 10. PROBLEMA: Falta de tratamento de timeout

### Arquivo: `main.py`

### Problema:
A função `_executar_consulta` não trata adequadamente de timeouts:

```python
def _executar_consulta(self, registro: dict):
    # ...
    page.goto(url, timeout=TIMEOUT_PER_REQUEST)
```

Se a página demorar mais de `TIMEOUT_PER_REQUEST` para carregar, a consulta falha.

### Solução:
Adicionar retry logic:
```python
max_retries = 3
for attempt in range(max_retries):
    try:
        page.goto(url, timeout=TIMEOUT_PER_REQUEST)
        if page.is_loading():
            time.sleep(1)
            continue
        break
    except Exception as e:
        if attempt == max_retries - 1:
            raise
        time.sleep(2)
```

## 14. PROBLEMA: Performance em consultas em lote

### Arquivo: `main.py`

### Problema:
O código não implementa fila de tarefas para consultas paralelas.

### Solução:
Usar `queue.Queue` e múltiplos workers:

```python
queue = queue.Queue()
workers = []
for _ in range(MAX_WORKERS):
    worker = Thread(target=worker_process, args=(queue,))
    worker.start()
    workers.append(worker)

# Adicionar tarefas à fila
for registro in registros:
    queue.put(registro)

# Esperar todos os workers terminarem
for worker in workers:
    worker.join()
```
